# Lab 8: Python Game Build Guides

Four build guides for the Lab 8 two-player Python game. Each guide covers the game's design, data structures, the functions to write, pseudocode, error handling, scoring, twists, and a testing checklist. Each also includes the shared requirements checklist, presentation tips, and a week plan, so you only need to open one.

> **Note:** These guides give you design and pseudocode, not finished code. The lab forbids copied source code, so you and your partner write every line yourselves.

## Which One Should You Pick?

**Want the fastest, safest finish?**
→ [Hangman](hangman_guide.md). The terminal logic is clean and easy to comment, and it's simple to explain in a presentation.

**Want the best error handling to show off?**
→ [Battleship Lite](battleship_lite_guide.md). Coordinate parsing, ship placement, and repeat shots give you plenty of bad input to catch during the live demo.

**Want the biggest "wow" in the demo?**
→ [Snake (Two-Player)](snake_guide.md). It's real-time, with both players on one keyboard. Pick it only if your team is comfortable with game loops and installing pygame.

**Want something familiar to build on?**
→ [Tic-Tac-Toe](tic_tac_toe_guide.md). It matches your instructor's `TTT.py` sample, so **you must add a twist** (a bigger board, disappearing marks, or an erase move) to make it clearly your own.

## How to Use These Files

1. Keep all five `.md` files in the **same folder** so the links work.
